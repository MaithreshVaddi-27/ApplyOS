## How to read the research documents

**These are analysis, not fact.** A competitive analysis is a set of judgements about other
projects, made from their public documentation at a point in time. It is dated, it is
partial, and it can be wrong.

Every factual claim about ApplyOS in these documents cites a file in this repository. Every
claim about *another* project cites that project's public documentation and is marked with the
date it was checked.

**No metric in these documents is measured unless it says so.** Star counts are stated with the
date they were observed; they are not a quality claim.
